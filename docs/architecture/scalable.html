Kickstream · scalable architecture
What ships today

Target shape of the product that already runs locally and as one Azure Container App.

One match owner. One encode. Viewers scale apart.

A live show cannot be split across copies: the match clock and the ffmpeg process each need a single owner. Viewers, hosts, narration, and the next show do not. This is that split, using the same pipeline the app already runs.

Locally the four workers are one FastAPI process on port 8000 and the Vite app on port 5173. The current Terraform deploy is the same process, with max_replicas = 1. This page is the shape to grow into. It is not what deploy/terraform creates today.

Inside one match

The match worker is the pipeline that already runs in services/pipeline. Scaling adds workers. It does not change the stages.

Inside one live show

Going live does not upload a file per platform. The encode worker opens the clean program, encodes once, and copies that stream.

What stays single-owner

The match clock

Score, minute, agents, and the live log have one writer. The lease is the lock. Restarting that worker resumes from Cosmos. It does not fork the match.

The encode

One hidden browser and one ffmpeg per broadcast. A restart drops that encode. Auto live can start its 24/7 stream again from saved settings. A studio show does not resume mid-encode by itself.

The region

First scale-out stays in centralindia, the region the deploy uses now. Cosmos is one geo location. There is no second-region failover in this design.

The model budget

Explainability stays at most 20 prose items a match. Ask Copilot stays at most 40 worded answers. MCP tools stay read-only and do not call a model or the web.

Not the Marketplace, and not StatsBomb in a paid offer. StatsBomb Open Data is non-commercial and stays off a paid deployment unless someone deliberately turns real sources on for a local, attributed use. This design does not add SaaS fulfillment, a purchase landing page, or a Partner Center offer. Foundry is an existing project the workers sign in to with a managed identity. Terraform does not create it.
